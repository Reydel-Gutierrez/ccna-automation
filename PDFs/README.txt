CCNA Automation study PDFs
==========================

These PDFs are print-friendly versions of the Markdown guides.
Use them for reading. Keep using the labs/ folder for code you actually run.

Suggested study order
---------------------
1. 00_Official_Exam_Blueprint_200-901_CCNAAUTO_v1.1.pdf
   Cisco's official outline. This is the authority for what is on the exam.

2. 02_Study_Plan.pdf
   8-week schedule (with faster/slower options).

3. 03_Lab_Setup.pdf
   What to install on Windows. After reading it, still run the commands
   from the Markdown/lab files.

4. Study the material
   Easier: chapters\Domain_1-2_....pdf then 3-4 then 5-6
   Or one book: 01_Complete_Study_Guide.pdf

5. 04_Objective_Checklist.pdf
   Tick off every official objective.

6. 05_Practice_Questions.pdf
   Stop before the "Answer key" page (it starts on a new page).

7. 06_Final_Review.pdf
   Last few days before the exam.

What is NOT a PDF (on purpose)
------------------------------
- labs\                  runnable Python, Docker, Ansible, Terraform
- CCNAAUTO_Study_Tracker.xlsx
  Keep this in Excel. The Status dropdown and colors do not work in PDF.
- Original files
  200-901-CCNAAUTO_v.1.1.pdf
  Automation-v2.0-Learning-Matrix.xlsx

Notes
-----
- Mermaid diagrams appear as labeled source blocks in the PDF.
  The Markdown files still have the diagram code if you want to render them in VS Code.
- This material is study content, not a Cisco exam dump and not a pass guarantee.
